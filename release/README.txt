MEGASTRUCTURE — сборка для Windows (64 бит)

Как играть: запустите Megastructure.exe.
Все три файла должны лежать в одной папке:
  Megastructure.exe                        — игра
  Megastructure.pck                        — данные игры (мир, звук, модели)
  libterrain.windows.release.x86_64.dll    — ландшафт горы

Управление: мышь — осмотреться, WASD — идти, Shift — бежать, Пробел — прыжок, Esc — отпустить мышь (клик — вернуть), выход — Alt+F4.
Нужна видеокарта с поддержкой Vulkan (GeForce GTX 900 / Radeon RX 400 и новее).
