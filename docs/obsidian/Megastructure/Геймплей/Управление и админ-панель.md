# Управление и админ-панель

| Клавиша          | Действие                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------- |
| W A S D          | идти                                                                                     |
| Shift            | бежать                                                                                   |
| Space            | прыжок (в полёте — вверх)                                                                |
| Ctrl             | в полёте — вниз                                                                          |
| Мышь             | осмотреться                                                                              |
| **Tab** (зажать) | показать задание («Нужно идти» → после рассказа об ангеле «Я должен найти его»)                                                         |
| **E**            | разжечь костёр в пещере (подойти ближе)                                                  |
| **T**            | закурить → чиркнуть зажигалкой; **держать T** — затяжка, отпустить — выдох → [[Курение]] |
| Esc / клик       | освободить / вернуть мышь                                                                |
| **F1**           | админ-панель                                                                             |
| **F**            | полёт вкл/выкл                                                                           |

**Задание.** В левом верхнем углу — полупрозрачный текст «Нужно идти» (после рассказа об ангеле — «Я должен найти его») (без плашки и обводки).
Появляется, как только герой встал после падения, и тает через ~7 с; потом — пока зажат Tab:
плавно проявляется и чуть выезжает слева, при отпускании плавно тает и уезжает обратно.

**Подсказка «Закурить - T»** — внизу экрана на 5 секунд, когда герой встал после падения.

**Админ-панель (F1):** FPS и высота · пропустить вступление · полёт, сквозь стены, скорость полёта ·
эффект бодикамеры · **регулятор бодикамеры** (линза, расслоение цвета, виньетка, зерно: 0–200%, 100 — как задумано) · **покачивание при ходьбе** (0–200%) · **крен при повороте камеры** (0–300%) · глобальное освещение (тяжёлое) · путь героя вручную (0–100) · скорость «сна» ·
позвать ангела · переставить вещь · припадок сейчас · подняться на 100 м · на старт ·
к началу тропы · на тропу над облаками · финал на вершине.

**Режимы запуска** (аргумент после `--`): `--demo` (прогулка со скриншотами), `--bench` (замер FPS),
`--map` (карта сверху). См. [[Тесты и проверка]].

## Клавиши (22.10.2026)
| Клавиша | Что |
|---|---|
| T | закурить, затяжка (держать) |
| Q | выбросить окурок |
| ПКМ (держать) | зум: плавное приближение, отпустил — отдаление |
| C | снимок бодикамерой (в финале — на слайдах; файлы — `user://photos/`) |
| E | разжечь костёр; сесть / встать на скамейке на мосту |
| Tab | показать задание |
| Esc | пауза |

## Подсказки (23.10.2026)
После подъёма — «Закурить - T», затем «Зум - ПКМ». Первый зум → «Фотографировать - C» (и когда исчезает существо
на мосту). Первая затяжка → «Выбросить окурок - Q».

## Меню и настройки (21–22.10.2026)
- **Главное меню** — после предыстории, прямо на кадре ночной крыши (см. [[Вступление — падение]]):
  «Начать новую игру», «Настройки», «Выход из игры» — только мышью.
- **Esc — пауза** (мир стоит, мышь свободна): «Продолжить», «Настройки», «Начать заново», «Выйти из игры».
  Во время пролога Esc паузу не открывает.
- **Настройки** сохраняются в `user://settings.cfg` (`scripts/settings.gd`), применяются сразу:
  звук (общий, музыка, звуки мира и шаги), мышь (чувствительность, инверсия), камера (бодикамера, покачивание, крен —
  то же, что в админ-панели, но насовсем), изображение (качество, разрешение 3D, яркость, полный экран,
  вертикальная синхронизация, ограничение FPS, живописный стиль, сглаживание MSAA и TAA, анизотропия).
  Раскрывающиеся **«Расширенные настройки графики»**: разрешение 3D, SDFGI, SSIL, SSR, SSAO, качество тумана и
  теней, блюм, FXAA — пресет качества выставляет их разом. По умолчанию (22.10): крен 245%, бодикамера 150%,
  без вертикальной синхронизации, живопись выключена. «Сбросить» — всё как задумано.
- **Качество графики:** Высокое — как задумано; Среднее — без глобального освещения (SDFGI, SSIL);
  Низкое — ещё без отражений и затенения, туман грубее, без мазков живописи, 3D в 75% разрешения (FSR).
  Замер (RTX 2060, 5 точек): Высокое 92–115 FPS, Среднее 116–146, Низкое ~180 (упирается в частоту экрана).
  Видеопамять 1095 → 662 → 532 МБ. Это и есть «режим для слабых ПК» из бэклога.
- Вид — в стиле игры: полупрозрачный текст без плашек (`scripts/menu_ui.gd`, `settings_panel.gd`, `pause_menu.gd`).
- Проверка: `tests/menu_test.gd -- --prologue` (входит в регрессию).
