# Путь героя

Мир меняется по мере того, как герой уходит от города и поднимается.

| | Город | Мост | Над облаками |
|---|---|---|---|
| Дождь | ледяной, косой | стихает | нет |
| Небо | свинцовое, холодное | светлеет | тёплое, закат |
| Солнце | высоко, бледное | — | низко над облаками, прямо впереди |
| Туман | клочья, неон в нём | реже | почти нет |
| Цвета | приглушённые | теплеют | насыщенные |
| Ангел | зовёт к горе | зовёт | исчезает |

Дорога даёт до 70% «тепла», остальное — только выход выше облаков (330–450 м).

Для проверки в админ-панели: «Путь героя вручную» + ползунок 0–100.
