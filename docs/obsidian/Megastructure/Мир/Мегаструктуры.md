# Мегаструктуры

~150 гигантов вокруг города до 2,4 км — растут прямо из бездны (основания до -900 м).

| Тип | Описание |
|---|---|
| Аркологии | башни 250–1200 м с тысячами горящих окон (шейдер фасада) |
| Бетонные гиганты | ступенчатые, с карнизами, окнами-щелями, рёбрами |
| Круглые башни | с металлическими кольцами |
| Каркасы | колонны и перекрытия, часть этажей обрушена (BLAME!) |
| Иглы | пучки тонких башен до 900 м |
| Стены | длинные, с контрфорсами и проходами |
| Плиты-потолки | гигантские плиты на опорах на высоте 280 и 420 м |
| Ворота | на мосту к горе, 260 м |

Плюс: мосты и трубы между башнями (только за городом, не больше 3 на башню), гигантская реклама на ближних, прожекторы шарят по небу.
