# Terrain3D

Аддон для ландшафтов (v1.0.2). Им сделана [[Гора]] — полностью из кода, по карте высот.

## Грабли, на которые наступили
| Симптом | Причина | Решение |
|---|---|---|
| Шахматная клетка | нет текстуры / настройки сброшены | текстура камня + настраивать **после** `add_child` |
| Бесконечный плоский пол | фон мира по умолчанию — плоскость | `material.world_background = 0` |
| Высоты NaN, гора не там | карта пишется с угла региона, а не с заданной точки | выравнивать начало карты по сетке регионов |
| Размер региона не меняется | свойство до добавления в сцену не применяется | `change_region_size()` после `add_child` |
| Сотни ошибок «material is null» | замена материала на новый | менять существующий материал, не заменять |
| Проваливаешься при телепорте | коллизия только вокруг камеры | (было) `collision_mode = 3` — см. строку ниже |
| **Игра зависает у горы** | дыры в коллизии Terrain3D — это NaN; физика героя над ними пишет тысячи предупреждений в секунду | `collision_mode = 0` и **своя** `HeightMapShape3D` по той же карте: на месте дыр −900 м вместо NaN; узел масштабирован в `SPACING` (равномерно), высоты поделены на `SPACING` |
| Плоский «пол» под горой (квадраты регионов) | регион заполняется целиком, за краем карты высота 0 | карта на весь регион + **дыры**: управляющая карта со значением `Terrain3DUtil.as_float(Terrain3DUtil.enc_hole(true))` везде вне горы и ниже −480 м |

Подробно — навык `terrain3d-from-code` (с уроками про дыры и NaN) → [[Навыки для будущих проектов]].
