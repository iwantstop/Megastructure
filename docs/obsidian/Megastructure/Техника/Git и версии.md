# Git и версии

Репозиторий — в папке проекта и на GitHub (**приватный**): https://github.com/iwantstop/Megastructure
Аккаунт: `@iwantstop` (вход через GitHub CLI `gh` выполнен).

- Ветка `angel-story` — основная работа (по умолчанию на GitHub), `main` — до истории.
- Папка `release/` — готовая игра для Windows, большие файлы через **Git LFS** → [[Сборка и публикация]].
- Игрокам — релиз `v0.2` в разделе Releases (не Download ZIP!).

## Открыть проект на другом компьютере
1. Поставить Git для Windows (Git LFS входит в него).
2. `git clone https://github.com/iwantstop/Megastructure`
3. Godot 4.7 → **Import** → `project.godot`.

## Метки
| Метка | Что это |
|---|---|
| `city-v5` | обычный город, до истории про ангела |
| `abyss-v1` | город над бездной, лифты, мост (первый видеоотчёт) |
| `abyss-v1.1` | первая сборка .exe, быстрая генерация мира |
| `v0.2` | релиз на GitHub: гора, падение, финал, оптимизация, дыры под горой, без веера мостов |
| `v0.3` | ангел-проводник, субтитры, задание (Tab), пробуждение по W, финал без текста |
| `v0.4` | живописный стиль, исправления плейтеста, припадки на мосту, «Я должен уйти», «Это... Всё я» |
| `v0.5` | экран загрузки, звуки мира, гора с уступами и пещерой-квартирой, костёр, прощание ангела, руки, сигарета в истории |

Вернуться к версии: «верни city-v5» — Claude переключит.
В git не входят: `.godot/`, `build/`, `screenshots/`, сырой звуковой пак.
