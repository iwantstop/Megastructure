# Git и версии

Репозиторий — в папке проекта и на GitHub (**приватный**): https://github.com/iwantstop/Megastructure
Аккаунт: `@iwantstop` (вход через GitHub CLI `gh` выполнен).

- Ветка `angel-story` — основная работа (по умолчанию на GitHub), `main` — до истории, `painterly` — старая ветка
  живописного стиля (слита в `angel-story` в v0.4).
- Папка `release/` — готовая игра для Windows, большие файлы через **Git LFS** → [[Сборка и публикация]].
- Папка `docs/obsidian/` — копия этой базы заметок (обновляется вместе с коммитами; открыть в Obsidian как хранилище).
- Папка `assets/characters/officer/` — модель офицера (`officer.glb`), исходник Blender — в `source/`.
- Игрокам — **последний релиз `v0.7.1`** в разделе Releases (не Download ZIP!):
  https://github.com/iwantstop/Megastructure/releases/tag/v0.7.1
- Коммиты подписаны соавтором `Claude Opus 5.5`; push — после крупных изменений, по просьбе автора.

## Открыть проект на другом компьютере
1. Поставить Git для Windows (Git LFS входит в него).
2. `git clone https://github.com/iwantstop/Megastructure`
3. Godot 4.7 → **Import** → `project.godot`.
