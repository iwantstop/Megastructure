# Навыки для будущих проектов

Всё, что придумали и отладили в Megastructure, разобрано на **навыки Claude** — отдельные инструкции
с рабочим кодом и уроками. Лежат в `C:\Users\User\.claude\skills\`, по папке на навык (`SKILL.md`).
В новом проекте Claude сам подхватит нужный навык по смыслу задачи — или можно попросить прямо:
«используй навык godot-fp-smoking».

## Решения автора, которые стоит помнить в новых проектах
- Укачивает → камера без тряски в покое, только дыхание; эффекты — экранные, не тряской.
- Не осветлять картинку без просьбы; контраст важнее.
- Текст на экране — без плашек и обводки, полупрозрачный, всё плавно.
- Случайно бродящие NPC без маршрутов — «выглядит не очень».
- Мазки/фактура должны принадлежать поверхностям, а не экрану; вдали — чисто.
- Меню — только мышью; тряска камеры — только в падениях и разбеге.
- Иногда просит не запускать регрессию после правок — «проверю сам».
- Ключи API и пароли вводит сам, не Claude.
- Любит видеоотчёты, таблицы «до/после» и чтобы Claude сам проверял.
