# Шейдеры и атмосфера

| Шейдер | Что делает |
|---|---|
| `concrete.gdshader` | бетон/штукатурка/кирпич: пятна, потёки, грязь у земли, панели со швами, лужи с отражениями; мелкие детали гаснут вдали (против ряби) |
| `facade.gdshader` | сетка окон небоскрёбов: этажи, рёбра, горящие окна (тёплые/холодные, шторы), отражение неба |
| `hologram.gdshader` | голограммы: светятся, полупрозрачные, полосы развёртки, мерцание |
| `clouds.gdshader` | слой туч на 420 м: снизу свинцовые, сверху белые, плывут |
| `bodycam.gdshader` | экранный эффект [[Камера бодикам]]; в ветке `painterly` — ещё мазки и гамма зоны → [[Живописный стиль]] |

## Туман
- Цвет тумана берётся с неба → нет шва на горизонте.
- Базовая объёмная дымка редкая, чтобы был виден масштаб; густые **клочья** — FogVolume с 3D-шумом, медленно дрейфуют.
- В бездне туман сгущается до сплошного моря.

## Свет
Пасмурное небо, мягкие тени, неон с сильным свечением (не «неосвещаемый», иначе не светится),
глобальное освещение SDFGI + SSIL + отражения SSR (лужи), сглаживание TAA.

Связано: [[Путь героя]] · [[Город]]
