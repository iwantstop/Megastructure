# Архитектура кода

Весь мир строится **кодом при запуске** (~3 с): `main.tscn` — пустой узел со скриптом `world.gd`.
Поэтому в редакторе Godot мир не виден — см. [[Бэклог]] (идея: показать мир в редакторе).

| Файл | Отвечает за |
|---|---|
| `scripts/world.gd` | сборка всего: материалы, небо, туман, свет, порядок создания, режимы `--demo/--bench/--map` |
| `scripts/builder.gd` | склейка геометрии в куски, коллизии, окклюдеры → [[Генерация мира]] |
| `scripts/structures.gd` | генератор: город, уровни, платформа, мост, мегаструктуры |
| `scripts/mannequins.gd` + `crowd.gd` | где стоят манекены и их модели/позы |
| `scripts/props.gd` | вещи «на двоих» |
| `scripts/mountain.gd` | гора на [[Terrain3D]] |
| `scripts/player.gd` | игрок и [[Камера бодикам]], полёт, шаг на бордюры |
| `scripts/prologue.gd` | пролог на экране загрузки → [[Вступление — падение]] |
| `scripts/intro.gd` | [[Вступление — падение]] |
| `scripts/finale.gd` | [[Финал на вершине]] |
| `scripts/journey.gd` | [[Путь героя]]: погода и свет по ходу пути |
| `scripts/presence.gd` | [[Ангел]] |
| `scripts/cry.gd` | тихий плач из кода (всхлипы, вдох, «мм»; голос через форманты) — при «Прости меня...» |
| `scripts/dream.gd` | «сон»: вещи переставляются (шпиль убран) |
| `scripts/hud.gd` | задание «Нужно идти» → «Я должен найти его» (Tab), подсказка «Закурить - T», субтитры, рассказ посреди экрана (`narrate`) |
| `scripts/smoke.gd` | [[Курение]]: пачка, сигарета, Zippo, дым, синтезированные звуки |
| `scripts/fp_hands.gd` | руки в перчатках для курения (выключены, `SHOW_HANDS`) |
| `scripts/mountain_features.gd` | уступы, пещера, «неправильная» квартира → [[Гора]] |
| `scripts/campfire.gd` | костёр по E |
| `scripts/soundscape.gd` | [[Звук и музыка]]: петли по зонам, шаги, пианино |
| `scripts/seizure.gd` | припадки на мосту и у подножия горы: срыв кадра, перенос, субтитры |
| `scripts/flashback.gd` | выход из пещеры → 2 с падения с небоскрёба → к месту прощания |
| `scripts/bandages.gd` | падающие бинты на горе |
| `scripts/falls.gd` | люди, срывающиеся с крыш |
| `scripts/traffic.gd` | летающие машины (MultiMesh); трассы с облётом зданий |
| `scripts/elevator.gd` | лифты со створками |
| `scripts/admin.gd` | [[Управление и админ-панель]] |
| `scripts/progress.gd` | что остаётся между кругами и запусками: число сигарет (`user://progress.cfg`) |
| `scripts/photos.gd` | снимки бодикамерой (C), сохранение в `user://photos/` |
| `scripts/bench_spot.gd` | скамейка и торшер на мосту, сидеть — время быстрее, туман гуще |
| `scripts/ad_voices.gd` | голоса рекламы (синтез речи Windows) |
| `scripts/creature.gd` | существо на мосту (Mixamo + анимация пака через ретаргетинг) |
| `scripts/settings.gd` | **настройки игрока**: хранение (`user://settings.cfg`), применение звука, окна, камеры, качества |
| `scripts/menu_ui.gd`, `settings_panel.gd`, `pause_menu.gd` | вид меню, экран настроек, пауза по Esc (главное меню — в `prologue.gd`) |
| `scripts/game.gd` | **справочник** частей игры: `Game.player`, `Game.hud`, `Game.smoke`, `Game.presence`, `Game.mountain_features`, `Game.sun` (заполняет world.gd) |
| `scripts/synth.gd` | **звук из кода**: `Synth.wav`, `wav_from`, `play_once` (проиграть и удалить), рёв ветра `WindRoar` |
| `scripts/shapes.gd` | **заготовки**: материал, светящийся материал, коробка, цилиндр, шар, мягкая точка для частиц |
| `scripts/screen_text.gd` | **экранный текст**: абзац по центру, подсказка в углу, чёрный экран |
| `scripts/demo.gd`, `bench.gd`, `map.gd` | [[Тесты и проверка]] |
| `shaders/*.gdshader` | [[Шейдеры и атмосфера]]; `paint_strokes` и `bodycam` — [[Живописный стиль]] |
| `tests/*.gd` | автотесты; `tests/probes/` — разовые пробы-справки |

**Аддоны:** Terrain3D (гора), GodotRetro, Dialogue Manager, Asset Placer.
**Ассеты:** `assets/characters/` (манекен + 46 анимаций, RPG-персонаж + 64 анимации),
`assets/sounds/sfx_starter_pack/` (~140 звуков, в git не входит).
