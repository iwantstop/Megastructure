# Сборка и публикация

## 🎮 Скачать игру
**https://github.com/iwantstop/Megastructure/releases/tag/v0.7.1** → `Megastructure-v0.7.1-windows.zip` (122 МБ) → распаковать → `Megastructure.exe`.
(Все версии — в разделе Releases: `v0.2` гора над бездной, `v0.3` ангел-проводник, `v0.4` живопись и припадки, `v0.5` гора, пещера, руки, `v0.6` финал, меню, механики, `v0.7` ночная крыша, машина, новые тексты, `v0.7.1` исправлено зависание после машины.)

> ⚠️ Кнопка **Code → Download ZIP** на главной странице репозитория **не годится**: вместо exe и pck
> в архиве текстовые ссылки Git LFS (exe 134 байта — «не запускается»). Игру брать только из Releases.
> Чтобы и Download ZIP работал: Settings → General → Archives → *Include Git LFS objects in archives*.

## Как собирается
- Шаблоны экспорта Godot 4.7.2 — в `%APPDATA%\Godot\export_templates\4.7.2.stable\` (только Windows).
- Пресет «Windows Desktop» (`export_presets.cfg`), `embed_pck=false` — три файла:

| Файл | Размер | Что это |
|---|---|---|
| `Megastructure.exe` | 109 МБ | движок Godot |
| `Megastructure.pck` | 59 МБ | данные игры: мир, звуки, модели |
| `libterrain.windows.release.x86_64.dll` | 3,5 МБ | ландшафт горы ([[Terrain3D]]) |

- Почему не один файл: GitHub не принимает файлы больше 100 МБ, а exe со встроенными данными весил 168 МБ.
  Но и сам exe (109 МБ) больше лимита, поэтому в репозитории файлы игры хранятся через **Git LFS**.
- Команда: `godot --headless --path <проект> --export-release "Windows Desktop" build\Megastructure.exe`
- Готовая сборка копируется в папку `release/` репозитория (+ `README.txt`: как запустить, управление).
