# Заметки Obsidian

Копия базы знаний проекта (`Megastructure`) из Obsidian. Открыть: в Obsidian — «Open folder as vault» → эта папка
(`docs/obsidian`). Главная заметка — `Megastructure/Megastructure — главная.md`.

Оригинал живёт в `Documents/Obsidian Vault/Megastructure` на компьютере автора; сюда копируется при обновлениях.
`docs/.gdignore` — чтобы Godot не импортировал картинки из заметок как ресурсы игры.
