# Разовые пробы

Не тесты, а справки и замеры, которые понадобились один раз (печатают данные, ничего не проверяют):

| Файл | Что печатает |
|---|---|
| `anim_test.gd` | анимации модели и двигаются ли кости |
| `bones_list.gd` | кости рук у моделей персонажей (есть ли пальцы) |
| `hand_bones.gd` | оси костей руки манекена — для рук в кадре |
| `inspect_glb.gd` | содержимое GLB: узлы, меши, скелет, анимации |
| `terrain_api.gd` | методы классов Terrain3D |
| `terrain_probe.gd` | принята ли текстура камня Terrain3D |
| `sit_probe.gd` | замер позы «сидит» (таз, колени, стопы) |

Запуск: `godot --headless --path <проект> -s res://tests/probes/<файл>.gd`
